# Что написать Claude Code

## Как начать (один раз)

1. Распакуй архив `groundtwin_starter.zip` в папку, например `Documents/groundtwin`.
2. Открой Терминал → перейди в папку: `cd ~/Documents/groundtwin`
3. Запусти Claude Code: `claude`
4. Скопируй и вставь **Сообщение 1** ниже целиком.

Claude Code сам прочитает файл `CLAUDE.md` в этой папке — там весь план, правила и источники.

---

## Сообщение 1 (вставить первым)

```
Привет! Это проект GroundTwin для NASA Space Apps 2026. Прочитай CLAUDE.md полностью — там весь план, правила хакатона и источники данных. Дедлайн сдачи: завтра, 15 ноября, 13:00 по Бишкеку; всё отправляем к 12:00.

Я начинающий программист. Говори со мной по-русски и после каждого шага коротко объясняй, что сделал код и зачем.

Начни с T0: настрой окружение, git и Google Earth Engine. Мой GitHub-репозиторий: https://github.com/<МОЙ_ЛОГИН>/groundtwin . Мой Google Cloud project id для Earth Engine: <ID_ПРОЕКТА>.

Потом T1 (земной радар RCM). Ноутбук уже есть в notebooks/. [Если запускала его в Colab: результаты лежат в папке data/ — используй их.]

Работай по порядку задач из CLAUDE.md, коммить после каждой задачи и в конце каждой задачи пиши мне: что готово, какие числа получились, что дальше.
```

## Сообщения на потом (по ситуации)

**Когда подруга даст цвета и шрифт:**
```
Подруга прислала бренд: фон #______, акцент #______, текст #______, шрифт ______ (Google Fonts). Обнови CSS-переменные сайта и шрифт.
```

**Если что-то долго не получается:**
```
Мы застряли на этом больше 20 минут. Включи запасной вариант из CLAUDE.md, пометь его в данных и на сайте как fallback, и переходи к следующей задаче.
```

**Контрольная точка в 23:30:**
```
Контрольная точка. Скажи честно: что работает, что нет, сколько времени нужно на недоделанное. Предложи, что урезать, чтобы к 12:00 завтра всё было сдано.
```

**Объяснить мне для питча:**
```
Объясни мне простыми словами, как работает [модуль/формула], и дай 2 вопроса, которые может задать жюри, с короткими ответами.
```

**Утром в воскресенье:**
```
Пиши статью (T7) по данным из data/. Каждое число — только из JSON. Потом README и тексты сабмишна (T8), потом финальная проверка T9 по чек-листу.
```

**Перед сдачей:**
```
Пройди чек-лист T9 по пунктам. Открой сайт, проверь все страницы, сверь числа на сайте, в статье и в data/. Выдай мне готовые тексты для каждого поля сабмишна из submission/project_page.md.
```

---

## Важно помнить
- Claude Code работает **на твоём компьютере** и может сам скачивать данные (RCM, PDS, Earth Engine) — в отличие от чата.
- Когда он просит разрешение на команду — читай, что он делает. Обычно жми «Yes».
- Не давай ему удалять папки и делать `git push --force`.
- Использование Claude Code — это тоже ИИ. Оно уже упомянуто в AI statement в CLAUDE.md.
