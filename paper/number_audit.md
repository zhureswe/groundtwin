# Number audit — site and paper (15 Nov 2026)

How the numbers stay consistent:
- **Site.** `docs/assets/app.js` reads every result number from `docs/data/*.json` at page load; no result numbers are typed into the HTML.
- **Paper.** `pipeline/12_paper.py` substitutes every result number from the same JSON files; the full list (104 keys) is in `paper/numbers.md`.
- **Agreement.** The site and the paper read the same JSON files, so they agree by construction.

## 3. Problems found and fixed during the audit
- The Radar ruler note said "100-m cells", but the RCM pixel size was never measured by our code. It now shows the real block size from earth_cpr.json (`look` × `look` pixels).
- The Method data table listed "USGS Known Terrestrial Analog Sites"; it now names the sources actually used (NASA Planetary Analog Explorer, USGS Terrestrial Analog Data Portal) and adds GMTED2010.
- The old "×3.6 better than chance" home stat was removed on 14 Nov (it is not in our results).
